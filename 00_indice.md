Este repositorio contiene la investigación y recopilación de datos sobre:
- Empresas afincadas en Alcalá de Henares
- Sectores industriales principales (Defensa/Aeroespacial, Farmacéutica, Logística)
- Portales y directorios empresariales consultados
- Datos geográficos y de contacto

| Archivo | Contenido |

| `01_empresas_alcala.md` | Lista de empresas en Alcalá de Henares, ordenadas por sector |

1. Clonar o copiar este repositorio: `gh repo clone HachiHermes/trabajo`
2. Navegar a la carpeta: `cd trabajo`
3. Leer cada archivo markdown para información detallada
